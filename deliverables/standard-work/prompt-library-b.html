    Common questions

    Frequently Asked Questions

    What is FLIGHT DECK AI? +

    AI help built by the FLIGHT DECK team: ready-made prompts for Wingmate, skills for Claude, and short lessons. The AI writes a first draft so you can work faster. You still check it and make the decisions.

    What is FLIGHT DECK? +

    FLIGHT DECK is how GE Aerospace runs its work. It is built on eight basics called Fundamentals, such as Standard Work (the best way to do a job, written down) and Problem Solving (finding the real cause of a problem and fixing it).

    What is the difference between Wingmate and Claude? +

    Both are AI assistants you can use at GE. With Wingmate, GE's own assistant, you pick a ready-made prompt from this page each time. With Claude, you add the FLIGHT DECK skills once and it follows our steps on its own. Use whichever one you already work in.

    What is a prompt? +

    A prompt is the instruction you give an AI. The prompts on this page are already written for FLIGHT DECK tasks. You only add the details of your own work, like your area, your numbers or your notes.

    Who is this page for? +

    Anyone at GE Aerospace who uses FLIGHT DECK. If you lead a team and are not sure how to start with AI, start here.

    Is this the same as GE Aerospace's AI portal? +

    No. The AI portal lists AI tools across the whole company. This page is only about AI help for FLIGHT DECK work.

    What is a Claude skill, and how do I use one? +

    A skill is a saved set of instructions that teaches Claude how FLIGHT DECK does a task, like a 5 Why. Add the FLIGHT DECK Skills Library once (the steps are above on this page), then ask Claude for help as you normally would. It uses the right skill on its own.

    Can I change a prompt to fit my team? +

    Yes. Every prompt is a starting point. Copy it, then change the details to match your team's work, your process and your numbers.

    Where are the calculators and other tools? +

    In the FLIGHT DECK Tool Library. They help you practice the Fundamentals, but they do not use AI, so they live there instead of here.

    What about agents? +

    An agent is an AI helper that can do several steps of a task on its own. FLIGHT DECK agents will be added here as they are ready, with what each one does and how to use it.

    My team built an AI solution others could use. How do we share it? +

    Use the feedback form at the bottom of this page. We want teams to share what they build, so nobody has to build the same thing twice.
