Why remaster it

From a box you type into — to how you navigate.

Basic SharePoint search

  • One flat list of blue links
  • Waits for you to press enter
  • Exact-match — easy to miss things
  • Pulls you out of the page you were on

Remastered

  • Results the moment you type
  • Grouped by fundamental, template, tool, video
  • Your term highlighted in every hit
  • Or hand it to Wingmate and just describe it
One search, two doors

Pick the way that fits the moment.

🔍
Option 1 · Structured

Scan & filter it yourself.

When you roughly know what you’re after. Type, watch results group and highlight, scope by type, open with the keyboard.

Option 2 · Ask Wingmate

Describe it in plain words.

When it’s complex or you don’t know the term. Tell Wingmate the problem and it routes you to the right fundamental, template, and tool.

Built for SharePoint

One content index. Two front doors.

Both structured search and Wingmate read the same client-side index of the hub — a pattern SharePoint supports today through an SPFx web part. The same setup can sit on the SP Search API once we confirm the connector.

1
Content index
One list of the hub — fundamentals, templates, tools, videos. Powers both doors.
2
SPFx web part
Renders structured search and the Wingmate view. No custom infrastructure.
3
SP Search API
Swap the data layer to live SharePoint search when the connector is confirmed — both interfaces stay.
