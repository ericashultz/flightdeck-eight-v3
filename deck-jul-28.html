04 · Release

The open question.

Page by page, or everything together.

Option A

Page by page.

  • First page live sooner. The last one lands later
  • Eight socialisation cycles
  • Eight teams, a dozen each
  • Each page lands with no context
  • An explainer per page
Option B

One release.

  • Socialise once
  • The change explains itself
  • One piece of education
  • Everything live together, as Phase 1 closes
  • More riding on one moment
04 · Release · The arithmetic

Page by page asks a lot
more of the teams.

Team reviews happen either way. The layer above them multiplies.

8×
Governance cycles
Steer co and leadership, once per release.
8×
Introductions to make
Alone, each page needs context. Together, they explain each other.
1×
If they go out together
Each team still reviews its own page either way.

Worth challenging. If steer co only needs to see this once, page by page gets cheaper.

04 · Release · Our recommendation

One release, with a beta
cohort in front of it.

Everything goes out together. A smaller group sees it first.

Who

The priority user group.

The group already lined up for acceptance testing.

How long

Two weeks.

Long enough to catch friction. Not another gate.

What tells us

Can they find things.

Fewer reports of not finding things.
