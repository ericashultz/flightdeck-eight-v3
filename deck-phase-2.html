01 · The shift

Phase 2 is not more tools.
It is the layer that reads them.

Phase 1 gives every Fundamental something that works. Phase 2 is what happens to the output.

What we proved

The Guided Plan Builder does not produce prose. It produces an objective, a measured gap, and rows that each carry an owner, a date and an expected impact.

Why that matters

Structure is the thing an assistant can act on. It can check whether the actions sum to the gap, challenge an unowned row, or ask why a date sits outside the quarter.

What is missing

Nothing carries that structure from the tool to Wingmate. The user finishes a plan and then re-explains it from scratch in a chat that knows nothing about it.

02 · The contract

Define the handoff once.
Every tool after it is free.

One shape, emitted by any tool, understood by the assistant. This is the whole of Phase 2 in one object — everything else is plumbing.

03 · The routes

Three ways to build it.

The difference is not the software. It is how many teams have to agree before anything ships.

A · GE hosts, Bttr builds

GE provides compute and model access. Bttr builds the API and the hub integration.

GE provides
Cloud space, a model endpoint, auth, a data-residency ruling
Bttr owns
The API, the context contract, agent behaviour, everything in the hub
Depends on
One GE decision, then nobody
Fewest hands between a change and it being live. This is the one we would pick.

B · Bttr hosts, GE lends the model

Orchestration runs on Bttr infrastructure and calls a GE model endpoint.

GE provides
A reachable model endpoint and credentials
Bttr owns
Hosting, the API, the contract, the agents
Depends on
Whether GE data may leave the tenant
Fastest to a working demo. The residency question decides whether it can ever be more than that.

C · GE internal teams build it

The API is specified by Bttr and built inside GE.

GE provides
The engineering, the infrastructure, the roadmap slot
Bttr owns
The specification and the front end
Depends on
Several teams and their own priorities
Most durable inside GE. Slowest to move, and every change re-enters a queue.
04 · The unlocks

Four things only GE can answer.

Each of these blocks the route above it. None of them needs a meeting — they need a decision.

01
Which model, reachable how?An endpoint and an auth method. Whether it is the same model Wingmate uses today, or a separate one we may call.
02
Where does the compute live?GE cloud space, as raised in the session, or Bttr infrastructure calling in. This is the fork between route A and route B.
03
May a completed plan leave the tenant?An action plan carries KPI figures and named owners. If it may not leave, route B is off the table for anything beyond a demo.
04
Who is the user, to the API?Whether the hub can pass a GE identity through, or whether the assistant treats every session as anonymous.
05 · The first build

Smallest thing worth shipping.

Not the whole companion. One loop, end to end, on the tool that already produces the right shape.

01 · Emit

The Guided Plan Builder writes the contract object when a plan completes. It already holds every field.

02 · Carry

“Check my plan” hands that object to the assistant instead of asking the user to re-type it.

03 · Coach

The assistant opens already knowing the objective, the gap and every row, and asks the first useful question.

04 · Prove

One Fundamental, one tool, one loop. If it holds, the other seven inherit it without new integration work.
